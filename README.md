# Align (backend)

Align is a mobile app idea for people who already scroll social media a lot. It does not try to stop scrolling. It makes scrolling intentional: the user sets an intention, chooses the apps they want to use (Instagram, YouTube, TikTok and others), and sees content that fits that intention.

This repository holds the backend.

## Status

Early stage. Only the project setup exists so far: a TypeScript environment and the first project files. Development is paused while I study data privacy and platform rules, so the product is built in a lawful and privacy-respecting way before more is added.

## Tech

TypeScript on Node.js, run with tsx.

## What is planned

- Setting an intention before scrolling
- Choosing which social media apps to include
- Showing content that matches the intention
- Handling user data in line with data protection law
